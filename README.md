# Primitive DB

Простая консольная система управления базой данных на Python.
Таблицы создаются командами, а данные хранятся в JSON-файлах.
Поддерживаются основные операции: создание и удаление таблиц,
добавление, чтение, обновление и удаление записей (CRUD).

## Установка и запуск

Требуется Python 3.12+ и [uv](https://docs.astral.sh/uv/).

```bash
uv sync
uv run database
```

Запускайте программу из корня проекта: файлы базы данных создаются
в текущей папке.

## Хранение данных

- `db_meta.json` — метаданные: список таблиц, их столбцы и типы.
- `data/<имя_таблицы>.json` — записи таблицы (список словарей).
  Папка `data/` создаётся автоматически при первом сохранении.

## Типы данных

| Тип    | Как записывать значение      | Пример             |
|--------|------------------------------|--------------------|
| `int`  | целое число без кавычек      | `28`               |
| `str`  | строка в кавычках `"` или `'`| `"Sergei Ivanov"`  |
| `bool` | `true` / `false` без кавычек | `true`             |

В каждую таблицу автоматически добавляется столбец `ID:int`.
Он заполняется сам (следующий номер после максимального) и не может
быть изменён через `update`.

## Команды

### Управление таблицами

| Команда | Описание |
|---|---|
| `create_table <имя> <столбец:тип> ...` | создать таблицу |
| `list_tables` | показать все таблицы |
| `drop_table <имя>` | удалить таблицу |
| `info <имя>` | столбцы таблицы и количество записей |

### Операции с данными

| Команда | Описание |
|---|---|
| `insert into <имя> values (<знач1>, <знач2>, ...)` | добавить запись |
| `select from <имя>` | показать все записи |
| `select from <имя> where <условие>` | показать записи по условию |
| `update <имя> set <столбец> = <значение> where <условие>` | обновить записи |
| `delete from <имя> where <условие>` | удалить записи |

### Общие команды

| Команда | Описание |
|---|---|
| `help` | справочная информация |
| `exit` | выход из программы |

## Правила записи условий

- Значения в `insert` перечисляются в порядке столбцов таблицы, **без ID**.
- Несколько изменений в `set` разделяются **запятой**:
  `set age = 29, name = "Anna"`
- Несколько условий в `where` объединяются словом **`and`**
  (запись подходит, если выполнены все условия):
  `where age = 28 and is_active = true`
- После запятой нужен пробел: `(28, true)`, а не `(28,true)`.
- Строки обязательно в кавычках. Внутри кавычек можно использовать
  пробелы, запятые и слово `and`: `"Ivanov, Sergei"`.
- Столбцы и типы значений проверяются по метаданным таблицы.

> ⚠️ `update` без `where` изменит **все** записи таблицы,
> `delete` без `where` удалит **все** записи.

## Пример работы

```
Введите команду: create_table users name:str age:int is_active:bool
Таблица users создана
Введите команду: insert into users values ("Sergei Ivanov", 28, true)
Введите команду: insert into users values ('Anna', 25, false)
Введите команду: select from users
+----+---------------+-----+-----------+
| ID |      name     | age | is_active |
+----+---------------+-----+-----------+
| 1  | Sergei Ivanov |  28 |    True   |
| 2  |      Anna     |  25 |   False   |
+----+---------------+-----+-----------+
Введите команду: update users set age = 29, is_active = false where name = "Sergei Ivanov"
Обновлено записей: 1
Введите команду: select from users where ID = 1
+----+---------------+-----+-----------+
| ID |      name     | age | is_active |
+----+---------------+-----+-----------+
| 1  | Sergei Ivanov |  29 |   False   |
+----+---------------+-----+-----------+
Введите команду: info users
Таблица: users
Столбцы: ID:int, name:str, age:int, is_active:bool
Количество записей: 2
Введите команду: delete from users where ID = 2
Удалено записей: 1
Введите команду: update users set ID = 5 where ID = 1
Ошибка: нельзя изменять ID напрямую
```

## Структура проекта

```
src/primitive_db/
├── main.py       # точка входа
├── engine.py     # цикл программы, разбор команд, вывод таблиц
├── core.py       # логика: create/drop таблиц, insert/select/update/delete
├── parser.py     # разбор условий set/where и значений
├── utils.py      # чтение и запись JSON-файлов
└── constants.py  # допустимые типы данных
```
